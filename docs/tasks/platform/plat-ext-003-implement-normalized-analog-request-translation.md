## Allowed scope

Pure deterministic request/netlist/model/probe translation and its manifest.

## Forbidden scope

- No engine process/library load, filesystem preparation, result mapping, numerical tolerance change, automatic model replacement, or imported R7 bundle ingestion.
- No raw user command, host path, external include, shell text, or undocumented native option may pass through.

## Required behavior and edge cases

- Identical immutable input and translator versions produce byte-identical private input and manifest.
- Hierarchical and display names map to collision-free private identifiers and round-trip through the map.
- SI dimensions are validated before conversion; display prefixes never alter stored values.
- Any approximation is explicitly authorized by the request and capability policy; otherwise translation rejects.
- Limits cover element/model count, nesting, token/line length, numeric range, generated bytes, and preparation estimate.

## Acceptance tests

1. `TEST-PLAT-EXT-003-ACCEPTANCE` checks byte-stable translation, complete ID reverse mapping, unit/dimension preservation, and deterministic ordering across the fixture matrix.
2. `TEST-PLAT-EXT-003-FAILURE` rejects mutable, mismatched, unsafe, ambiguous, oversized, dimensionally invalid, non-finite, and unsupported input before any engine or workspace exists.
3. Evidence records every source/dependency/translator/capability digest, expected and actual private-input digest, mapping coverage, and diagnostic.
4. The task documents any supported approximation and proves no PDF citation is used as an engine grammar or semantic specification.

## Known limitations

- This is a documentation-only `Planned` card; it proves no runtime behavior, engine installation, numerical correctness, security control, test result, or release status.
- Engine-specific facts, including any ngspice capability, callback, build, version, or model behavior, remain unsupported until the exact upstream source/build and current project evidence are pinned and reviewed under the Source and Evidence Policy.
- Completing this concern cannot authorize engine or model redistribution; a separate current license and distribution review is mandatory.
